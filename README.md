# MonitorSourceSwitch

### A quick and simple command line utility to switch the input source of a monitor using NVAPI and I2C commands.
### Created to switch my own monitor (LG UltraGear evo 45GX950B) from HDMI1 to HDMI2, DisplayPort or USB-C.
### You can experiment with the command line arguments to switch to other input sources, but I cannot guarantee that it will work for your monitor.
